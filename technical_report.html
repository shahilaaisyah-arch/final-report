Technical Report

Laptop Deployment & Imaging

During the industrial training period, laptop deployment and imaging activities were carried out to prepare devices for company users. The process included installing operating systems, rebuilding system images, joining laptops into the company domain, and configuring user settings. Active Directory was also used to create and manage computer objects to ensure proper integration within the company network environment. These tasks helped improve understanding of enterprise deployment procedures and device management processes.

Software Installation & Configuration

Various software installations and configurations were performed based on user requirements and company standards. Applications such as Microsoft 365, SAP Business One, Tekla Structures, Revit, and EXQL Reporting tools were installed and configured accordingly. In addition, security software including Zscaler, Symantec Endpoint Protection, VPN clients, and Qualys were deployed to ensure secure system access and compliance with company security policies. This experience enhanced technical skills in software management and enterprise application support.

Troubleshooting & Technical Support

Troubleshooting activities were frequently conducted to resolve hardware, software, and network-related issues faced by users. Problems such as Wi-Fi connectivity issues, keyboard malfunctions, SAP printing errors, RDP connection failures, SCCM imaging errors, and dongle connection problems were investigated and resolved using suitable troubleshooting methods. Remote support and direct technical assistance were also provided to users to ensure minimal disruption to daily operations. These activities strengthened problem-solving and analytical skills in handling real-world IT support situations.

Printer & Network Configuration

Printer and network configuration tasks were also performed throughout the internship period. These included configuring colour printing permissions, managing print server settings, adjusting duplex printing options, and supporting SAP print configurations for users. Network-related tasks such as checking connectivity issues, configuring wireless access, and supporting VPN connections were also carried out. Through these responsibilities, practical exposure to network support and printer management within an enterprise environment was successfully gained.
